# 荷卸し検証チェック（夜勤・手入力専用）

LINEで共有するURL: https://yshimano-dev.github.io/fuel-check-night-web/

## 使い方
1. ローリー到着直後に油面計の荷卸し前在庫レシートを印刷。
2. 「① 数字入力」で、荷卸し前POSのA欄→荷卸し前レシートB欄→荷卸し後POSのC欄→荷卸し後レシートD欄→今回入荷数量④を順番に入力。
3. 受け入れ完了後に在庫レシートをもう一度印刷すること。
4. 「② 紙へ転記」で誤差・誤差率・判定を確認。
5. 正式な紙の検証チェック表に手書きで記入し、前後の帳票と3枚1セットで保存する。

## タンクの固定対応
- No.1：14KL、H（ハイオク）
- No.2：48KL、R（レギュラー）
- No.3：14KL、D（軽油）
- No.10：20KL、K（灯油）
- No.4〜9：未使用（紙の表は空欄）

※ タンク管理表・レシートの灯油は4行目ですが、チェック表ではNo.10です。

## 判定
- ① = B - A
- ② = D - C
- ③ = ② - ①
- 誤差率 = ③ / ④
- H/R/D：|③| >= 400L または |③/④| >= 2.5% なら ×
- K：|③| >= 100L または |③/④| >= 2.5% なら ×
- ④ = 0 の場合は誤差率を算出せず、数量基準以上のときだけ × とする。
- 欠落数値は「要入力」。マイナス誤差も同じ絶対値基準を使用。

## 技術仕様
- サーバー機能・画像送信・OCR・AI APIは使っていません。
- HTML/CSS/JavaScriptだけの静的Webアプリ。Google Cloud/Cloudflareへの接続は不要。
- 各端末の入力数字のみ、その端末のlocalStorageに保存。新しい検証ボタンで削除。
- 入力フィールドは inputmode=numeric。iPhoneで数字キーボードを使用。
- デプロイ: GitHub Pages (main/root)。配達アプリと分離。
- 入力内容・○×判定は現場の正式な記録・責任者の判断を代替しません。
