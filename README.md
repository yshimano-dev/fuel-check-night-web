# 燃料荷卸し検証補助（夜勤用・試作）

スマホ向け静的Webアプリ。写真撮影・画像から数字候補を抽出・手入力修正・10タンクの誤差計算・判定結果の表示に対応します。

## 安全・プライバシー
- サイト上にユーザーの帳票、社内マニュアル、サンプル写真は同梱していません。
- アップロード先サーバーは設けておらず、撮影した画像とOCRはブラウザー内で処理します。
- 外部のTesseract.jsライブラリ（CDNから読み込み）を利用しています。撮影画像は当アプリのサーバーに保存しません。
- 入力された数値のみブラウザーのlocalStorageに一時保存されます。利用後は「全削除」を選択してください。
- ○×判定は補助情報です。受け入れ停止・販売停止・報告は現場の正式手順と責任者の判断に従ってください。
- 印字レシートとタンク管理表は現場の正式な運用に沿って扱い、検証チェック表は紙へ手書きし3枚セットで保存してください。

## 計算
- ① B−A、② D−C、③ ②−①、誤差率 ③÷④
- ガソリン・軽油は絶対誤差400L以上または2.5%以上、灯油は100L以上または2.5%以上を「×」で表示（提供された運用資料に準拠）。
- 出力は業務判断の代わりになりません。

## デプロイ
GitHub Pages の main / root を使用します。専用の別リポジトリで、配送アプリとは共有しません。
